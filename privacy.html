Privacy Policy

rocky is used only by its owner, with the owner's own Gmail account.

Data accessed: rocky reads messages carrying a specific Gmail label to find job commands, marks them as read, and sends reply emails with job results.

Use: Data is used only to run the requested jobs and reply to them. It is not sold, shared with third parties, or used for advertising.

Storage: Message IDs and job logs are stored only on the owner's own server.

Google user data: rocky's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access: Access can be revoked at any time at https://myaccount.google.com/permissions.
